# Разлом

Пошаговая roguelike-стратегия для Android. Отряд идёт по разветвлённой карте из восьми
переходов, дерётся на клетчатом поле и по дороге собирает бойцов и улучшения. Проигранный
бой заканчивает забег — сохранений внутри забега нет.

Написана на Kotlin и Jetpack Compose. Без игровых движков: вся графика рисуется на `Canvas`,
никаких сторонних зависимостей сверх Compose.

## Как играть

**Карта.** Каждый узел — один переход. Из текущего узла доступны один-два следующих, и выбор
между ними и есть главное стратегическое решение забега.

| Значок | Узел | Что происходит |
|---|---|---|
| `×` | Схватка | Обычный бой |
| `‡` | Логово | Элитный бой: врагов больше и они крепче |
| `≈` | Привал | Отряд лечится на 60% максимального здоровья |
| `+` | Наёмники | Бесплатный выбор одного бойца из трёх |
| `Ω` | Пожиратель | Босс на восьмом переходе, конец забега |

**Бой.** Поле 7×9, ходы раздаются по инициативе — каждый раунд очередь пересобирается
заново и показана полоской сверху. На своём ходу боец тратит запас шагов (подсвеченные
клетки) и один раз атакует; атака завершает ход. Тап по врагу в красной рамке — удар, тап
по любому юниту — посмотреть его характеристики.

**Между боями.** Здоровье переносится из боя в бой: недобитый лучник так и пойдёт дальше
недобитым. Павшие после победы поднимаются с четвертью здоровья. После каждого боя дают
выбрать одну награду из трёх — нанять бойца (в отряде максимум пять), +2 к атаке всем,
+6 к максимальному здоровью всем или полное исцеление.

## Бойцы

| Боец | HP | Атака | Дальность | Ход | Особенность |
|---|---|---|---|---|---|
| Латник | 34 | 8 | 1 | 3 | — |
| Копейщик | 26 | 7 | 2 | 3 | Пробивает второго врага на линии |
| Лучник | 18 | 6 | 4 | 2 | — |
| Маг | 16 | 9 | 3 | 2 | Половина урона расходится по соседям цели |
| Знахарь | 20 | 9 | 3 | 3 | Лечит союзника вместо удара |
| Разбойник | 22 | 7 | 1 | 5 | +50% урона, если рядом с целью стоит свой |

Стартовый отряд — Латник, Лучник и Знахарь. Остальных набирают по дороге.

## Сборка

Нужен JDK 11+ (подойдёт тот, что идёт с Android Studio) и Android SDK.

```bash
./gradlew :app:assembleDebug          # APK в app/build/outputs/apk/debug/
./gradlew :app:testDebugUnitTest      # тесты боевой логики
./gradlew installDebug                # поставить на подключённое устройство
```

`minSdk` — 36 (Android 16). Понижение потребует только пересборки: ничего специфичного для
новых API в коде нет.

## Структура

```
app/src/main/java/io/github/prostagma1/razlom/
├── game/          игровая логика, ничего не знает про интерфейс
│   ├── Model.kt   бойцы, характеристики, способности
│   ├── Battle.kt  пошаговый бой, поиск пути, ИИ противника
│   ├── Run.kt     карта забега, награды, генерация врагов
│   └── Game.kt    состояние забега и переходы между экранами
└── ui/            Compose: экраны, отрисовка поля, анимации
```

Боевая логика отделена от интерфейса и покрыта unit-тестами
(`app/src/test/.../BattleTest.kt`): движение через препятствия, урон, способности, условия
победы и то, что ИИ не зацикливается.
